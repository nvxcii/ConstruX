# The Universal Analytical Framework (UNAF) v1.0
## A Content-Agnostic System for Traceable, Transparent, and Balanced Analysis

**Purpose:** Allow a user to break down any material — a document, conversation, data set, or situation — to produce an evidence-based analysis aligned with transparency, balance, proportionality, and self-correction.

**Content-agnostic by design.** The framework applies universally because it targets the structure of human reasoning itself, not the subject matter.

**Version:** 1.0 — Manual completion. Automation reserved for v2.0 after field-testing.

---

## The Seven Structural Principles

| # | Principle | What It Means |
|---|-----------|---------------|
| P1 | Separate Observation from Interpretation | Raw data captured verbatim before any analysis. No conclusions in the evidence phase. |
| P2 | Exhaustive, Forced Documentation | Every layer requires specific fields. No skipping. Tables, checklists, written statements are mandatory. |
| P3 | Built-in Adversarial Testing | Articulate the strongest counter-argument to your preferred interpretation before concluding. |
| P4 | Layered Independence | Each layer is logically independent. If one collapses, others should not automatically collapse. |
| P5 | Proportionate Claiming | Absolute language forbidden unless incontrovertible. Use calibrated qualifiers instead. |
| P6 | Uncertainty Acknowledgment | Explicitly state what you do not know and what evidence would resolve it. |
| P7 | Actionable Output with Fallback | Every analysis concludes with a specific, proportionate action and a fallback position. |

---

## How to Use This Framework

1. Gather all source material. Do not rely on memory.
2. Set aside your preferred outcome. The framework will force you to consider conclusions you do not like.
3. Work through each layer **in order**. Do not skip ahead.
4. Write in complete sentences. Vague entries defeat the purpose.
5. If a field does not apply, write `N/A — reason: [explain]` rather than leaving it blank.

**Time estimate:** 20–45 minutes for a complex topic; 5–10 minutes for a simple one.
