Configuration Guide

Setting API Keys

API keys are supplied via environment variables. They are never persisted to disk.


  • export ANTHROPIC_API_KEY=sk-ant-...
  • export GOOGLE_API_KEY=AIza...
  • export OPENAI_API_KEY=sk-...
  • export DEEPSEEK_API_KEY=sk-...

Running the Server

  • Start: python app.py → http://localhost:8080
  • Custom port: PORT=9090 python app.py
  • Framework CLI: python -m multi_ai_framework.example_usage

Additional Config

Non-key settings can be stored in ~/.multi_ai_framework/config.json (created automatically on first run). Environment variables always take precedence over this file.
