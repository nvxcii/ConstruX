### SFI Enforcer (Speech Freedom Invariant)

Protects expression rights by detecting and preventing:
- Content suppression without legitimate cause
- Viewpoint discrimination
- Chilling effects on expression
- Prior restraint mechanisms

### TVP Enforcer (Truth Verification Protocol)

Ensures reality verification through:
- Claim verification pipelines
- Source credibility assessment
- Consistency checking
- Epistemic status tracking

### APA Engine (Autonomy Preservation Algorithms)

Protects self-determination by detecting:
- Manipulation patterns (dark patterns, artificial urgency)
- Coercion indicators
- Dependency creation
- Invalid consent mechanisms

### Rights Ledger

Immutable audit trail providing:
- Cryptographic integrity verification
- Historical pattern analysis
- Accountability and transparency
- Blockchain-inspired chaining

### DPAP++ Transformer

Converts violations into capabilities through:
- Violation-to-detection transformation
- Constraint-to-protocol conversion
- Attack-to-defense learning
- Antifragile strengthening

## Usage Example

```python
from white_mirror import WhiteMirrorOrchestrator

# Initialize the unified system
wm = WhiteMirrorOrchestrator(user_id="user_001")

# Evaluate an action
result = wm.evaluate({
    "type": "content_moderation",
    "description": "Removing user post",
    "actor": "platform",
    "target": "user",
    "consent": False
})

# Track a decision
wm.record_decision(
    description="Chose to implement feature A over B",
    conscience=0.4,  # Ethical considerations
    intuition=0.3,   # Gut feeling
    logic=0.3,       # Analytical reasoning
    domain="professional"
)

# Get system state
state = wm.get_system_state()

# Apply meta-recursion (system evaluates itself)
meta = wm.apply_meta_recursion()
```
