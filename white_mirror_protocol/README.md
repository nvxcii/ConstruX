The White Mirror Protocol is included in this repository. No additional installation needed.

# Use

## API Reference

### WhiteMirrorProtocol

Main orchestration class.

**Methods:**
- `operate_step(input_data)` - Execute one operation step
- `evolve(iterations)` - Evolve system through multiple iterations
- `process(data)` - Process data through the protocol
- `get_system_state()` - Get complete system state
- `get_dashboard()` - Get human-readable dashboard
- `export_state(filepath)` - Export state to file

### WhiteMirrorAIOrchestrator

Meta-orchestration for Multi-AI Framework.

**Methods:**
- `execute_mission_with_meta_orchestration(case_data, export_dir)` - Execute meta-orchestrated mission
- `evolve_orchestration(iterations)` - Evolve orchestration strategy
- `get_meta_orchestration_dashboard()` - Get combined dashboard
- `export_meta_state(filepath)` - Export meta-state
